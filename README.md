# Text Analytics en Español con Python

Material docente complementario al video **“Análisis de Sentimiento Twitter + Power BI + Python”**, publicado en 2021. El repositorio conserva el notebook utilizado para introducir técnicas básicas de procesamiento de lenguaje natural y análisis de sentimiento.

## Video asociado

▶️ **YouTube:** https://youtu.be/37JyRm0p7Kw

## Contenido del repositorio

- `Text-Analytics_Git-Hub.ipynb`: notebook Jupyter con los ejemplos desarrollados como apoyo al material audiovisual.

El notebook trabaja, entre otros, los siguientes contenidos:

- tokenización con **spaCy** y **NLTK**;
- distribución de frecuencias;
- identificación y eliminación de *stop words* en español;
- *stemming* y lematización;
- etiquetado gramatical (*POS tagging*);
- análisis de sentimiento con **TextBlob**;
- ejemplos de análisis de sentimiento en español mediante `sentiment-analysis-spanish`.

## Tecnologías utilizadas

El material original utiliza **Python 3**, Jupyter Notebook y bibliotecas como:

- NLTK
- spaCy
- TextBlob
- Matplotlib
- sentiment-analysis-spanish

El notebook registra un entorno original basado en **Python 3.7.3**.

## Uso docente

El repositorio fue creado para que estudiantes y personas que siguieran el video pudieran consultar, reutilizar y experimentar con el código mostrado en la demostración.

Su propósito es principalmente **didáctico**: presentar operaciones fundamentales de procesamiento de texto y mostrar algunas alternativas disponibles en ese momento para trabajar con español.

## Vigencia tecnológica

Este notebook corresponde a un entorno de trabajo de **2021**. Las versiones de Python, NLTK, spaCy, TextBlob, scikit-learn y otras dependencias han evolucionado desde entonces.

Además, el propio notebook señala limitaciones de algunas técnicas y recursos originalmente orientados al inglés cuando se aplican directamente al español. Por ello, el material se conserva **como recurso docente e histórico asociado al video original** y puede requerir ajustes para ejecutarse en entornos actuales.

No se han modificado los ejemplos originales con el propósito de mantener la correspondencia entre el código disponible en GitHub y el contenido presentado en el video.
